# Color Trigger Generator

**Geode мод для Geometry Dash 2.2074 (Windows)**

Автоматически создаёт столбик Color Trigger-ов и сдвигает цветовые каналы у выделенных объектов при склейке уровней в стиле Travel-уровней. Аналог функции _«Create Color Triggers»_ из BetterEdit 2.1, переписанный под Geode SDK 4.x.

---

## Структура проекта

```
colortrigger-mod/
├── mod.json                   # Манифест мода (Geode)
├── CMakeLists.txt             # Сборочный скрипт
├── build.bat                  # Быстрый запуск сборки (Windows)
└── src/
    ├── ColorTypes.hpp         # Типы: CapturedColor, системные константы
    ├── ColorUtils.hpp         # Утилиты: сбор каналов, поиск свободного смещения
    ├── TriggerFactory.hpp     # Создание игровых объектов Color Trigger
    ├── ColorTriggerPopup.hpp  # UI: модальное окно настроек
    └── main.cpp               # Хуки EditorUI + EditorPauseLayer, точка входа
```

## Сборка

1. Установите [Geode CLI](https://docs.geode-sdk.org/getting-started/create-mod/), убедитесь, что переменная окружения `GEODE_SDK` указывает на папку с SDK.

2. Клонируйте/скопируйте папку проекта.

3. Запустите:
   ```bat
   build.bat
   ```
   _или вручную:_
   ```bat
   mkdir build && cd build
   cmake .. -G "Visual Studio 17 2022" -A x86 -DCMAKE_BUILD_TYPE=Release
   cmake --build . --config Release
   ```

4. Скопируйте `ColorTriggerGen.geode` из `build\RelWithDebInfo\` в папку `<GD>/geode/mods/`.

## Использование

### Вариант 1 — кнопка в редакторе
Маленькая кнопка **[CT]** (зелёный кружок) появится в панели инструментов редактора.

### Вариант 2 — кнопка в паузе редактора
В меню паузы редактора (нажмите «Пауза») появляется кнопка **«Color Triggers»**.

### Порядок работы
1. Выделите вставленный сегмент уровня (несколько или все объекты).
2. Нажмите кнопку **[CT]** или откройте паузу → **Color Triggers**.
3. В появившемся окне настройте параметры:
   - **Color ID Offset** — величина сдвига каналов (нажмите **Auto** для автоподбора).
   - **Fade Time** — длительность перехода в секундах (0 = мгновенно).
   - **System Colors** — галочки для каналов BG / Ground1 / Ground2 / Line / 3DL / Obj.
   - **Custom Channels** — диапазон кастомных каналов (1–999 по умолчанию).
   - **Shift Selected Object Colors** — сдвигать ли ID у самих объектов.
4. Нажмите **Create**.

Мод:
- Собирает RGB/Opacity/Blending/CopyColor для каждого активного канала.
- Пропускает каналы со стандартным белым цветом (255, 255, 255 / 100% / без блендинга).
- Расставляет триггеры вертикальным столбиком левее выделения (шаг 30 единиц).
- Автоматически выделяет все созданные триггеры, чтобы их можно было сдвинуть целиком.
- Регистрирует операцию в стеке Undo (Ctrl+Z отменяет всё одним шагом).

## Ключевые технические детали

### ColorUtils::findFreeOffset
Итерирует смещения от 1 до 999 и возвращает первое, при котором ни один из сдвигаемых каналов не коллидирует с уже существующими в уровне. Вызывается кнопкой **Auto**.

### TriggerFactory::generateColumn
Вызывает `LevelEditorLayer::createObject(899, pos, false)` — официальный внутриигровой путь создания объектов, используемый редактором. Поля триггера заполняются напрямую через биндинги Geode.

### UndoObject
Оборачивает массив созданных объектов в `UndoObject` с типом `DeleteObjects`, что позволяет единственным нажатием Ctrl+Z удалить весь столбик.

### Производительность
Перебор 10 000+ объектов выполняется за O(N) за один проход без копирования данных. Единственные O(N log N) операции — `std::set` для сбора уникальных каналов, что приемлемо даже для крупных уровней.

## Известные ограничения

- **Системные каналы** (BG, Ground и т.д.) не сдвигаются у объектов, так как они глобальны для всего уровня — это намеренное поведение.
- Если суммарное число каналов × объектов очень велико (> 100 000), первый рендер после добавления может дать кратковременный фриз — это ограничение самого движка Cocos2d-x.
- Мод не затрагивает **Pulse Trigger** и **BG Effect Trigger** — только Color Trigger (ID 899).
